# Text Deadline

Небольшой FastAPI-сервис для расчета дедлайна и дат напоминаний.

Сервис принимает дату события, добавляет к ней 3 рабочих дня и возвращает:

- `deadline` - рассчитанный дедлайн;
- `reminders` - даты напоминаний за 1, 3, 7, 14 и 30 рабочих дней до дедлайна.

При расчете пропускаются субботы, воскресенья и официальные праздники России из библиотеки `holidays`.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
.venv/bin/python main.py
```

После запуска API будет доступен по адресу:

```text
http://127.0.0.1:8000
```

## Ручка

### POST `/calculate`

Пример запроса:

```json
{
  "event_date": "2025-06-02"
}
```

Пример ответа:

```json
{
  "deadline": "2025-06-05",
  "reminders": [
    "2025-06-04",
    "2025-06-02",
    "2025-05-27",
    "2025-05-16",
    "2025-04-18"
  ]
}
```

Если дата отсутствует или передана в неправильном формате, FastAPI вернет ошибку `422`.

## Тесты

В проекте есть 10 тестов:

- 4 теста проверяют API-ручку `/calculate`;
- 6 тестов проверяют функции `DeadlineService`.

Запуск:

```bash
.venv/bin/python -m pytest -q
```

Тесты проверяют успешный ответ ручки, ошибки валидации, расчет дедлайна без пропусков, перенос через выходные, перенос через праздники РФ и расчет дат напоминаний.
